单文件 exe，无需安装：下载后双击即可运行。首次启动会自动扫描你选定的 PDF 目录。

功能

  • 目录树扫描 + 阅读状态 / 进度 / 星标
  • 划词高亮、自由画线、矩形框选三种标注
  • 手写笔记（Markdown），可与标注双向互链、一键跳回 PDF 位置
  • JSON 导出 / 导入备份，兼容旧版格式
  • 深色 / 浅色主题，快捷键 J / K / 1-4 / S / /
  • 无网络依赖、无账号：文档与笔记只落在本机 %APPDATA%\recorder\
